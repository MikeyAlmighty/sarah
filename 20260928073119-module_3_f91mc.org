* Module 3 - Propositional Logic Part 1

** Key learning for this module:

- Understand *propositional logic* as a precise language for reasoning.
- Learn to build and interpret *truth tables*.
- Explore whether *logical statements* are *satisfiable*.

** Key concepts for this module:

- *Atoms* or *basic statements* (~true~ or ~false~).
- *Connectives*
- *Syntax*: rules for forming *well-formed formulae (wff)*.
- *Semantics*: truth tables define the meaning of statements.
- *Tautology* (always ~true~)
- *Contradiction* (always ~false~).
