#+title: The Identity Function

* The Identity Function

** Definition

The *identity function* on a set $A$ is $i : A \to A$ defined by

\[ i(x) = x \quad \text{for all } x \in A \]

Often written $i_A$ or $\mathrm{id}_A$ to make the set explicit.

** Role in composition

The identity is neutral under [[id:314e7721-01ba-4b56-a911-c12442325aac][Function Composition]]: for $f : A \to B$,

\[ f \circ i_A = f \qquad i_B \circ f = f \]

It is the "do nothing" function — used to define what it means for one function to /undo/ another (see [[id:8c4cf041-18fc-4d5b-91c1-933a5437eb5d][Invertible Functions]]):

$f$ and $g$ are inverses when $g \circ f = i_A$ and $f \circ g = i_B$.

** Example

With $f(x) = 2x - 1$ and $g(x) = \frac{x+1}{2}$ on $\mathbb{R}$:

\[ (g \circ f)(x) = \frac{(2x-1)+1}{2} = x = i(x) \]

so *composing* them gives back the *identity*.
