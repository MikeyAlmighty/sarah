Boolean Algebra Definition

Idea

Boolean algebras can be seen as an abstraction of Propositional Logic.

The strength of an abstraction is in its Generality.

The Generality lets it also cover set theory and digital circuit design.

Formal definition

A Boolean algebra is a tuple

\[ (B, +, \cdot, \bar{\ }, 0, 1) \]

\(B\)
set carrying the structure
\(+\), \(\cdot\)
binary operations (addition, multiplication; usually we write \(ab\) for \(a \cdot b\))
\(a \mapsto \overline{a}\)
unary operation (complementation)
\(0, 1\)
two special elements of \(B\)

Notes

  • B1 and B4 mean sums and products can be written without brackets.
  • B8 has no analogue in ordinary number arithmetic; it is the main surprise.
  • Axioms come in pairs that swap \(+ \leftrightarrow \cdot\) and \(0 \leftrightarrow 1\) (B3/B6, B7/B8, B9/B10).
  • Motivating instances: propositional logic, sets, circuits.

Example 2: The Lindenbaum algebra

The 8Boolean algebra* associated with PL:

  • Roughly, PL with \(\equiv\) replaced by \(=\).
  • set of equivalence wff \([A]\), where \([A]\) is the set of all wffs logically equivalent to \(A\)
  • Each subset \([A]\) is one element of \(B\)
