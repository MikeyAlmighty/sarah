#+title: Truth Tree Algorithm

* Truth Tree Algorithm

** Input

A wff \(X\).

** Procedure

1. Place \(X\) at the root of the truth tree.
2. Depending on its shape, apply either an \(\alpha\)-rule or a \(\beta\)-rule.
3. Place a ✓ against \(X\) to show it has been *used*.

Now repeat the following:

- *Close* any branch that contains an atom and its negation by placing a ✗ beneath the *leaf* defining that *branch*.
- If *all* branches are closed, *stop*: the tree is *finished and closed*.
- If not all *branches* are *closed* but the tree contains /only/ *literals* or used wff, *stop*: the tree is *finished and open*.
- Otherwise the tree is /not/ finished:
  - choose an unused wff \(Y\) which is *not* a literal;
  - for each *open* branch containing \(Y\), append the effect of the appropriate \(\alpha\)- or \(\beta\)-rule for \(Y\) to the *leaf* of that *branch*.

** Output

- Finished and *closed*: \(X\) is a *contradiction*.
- Finished and *open*: \(X\) is *satisfiable*.
  - To find all assignments making \(X\) ~true~:
    - For each open branch, assign \(T\) to all *literals* in that *branch*.
  - *Atoms* missing from a *branch* may be assigned ~truth~ values arbitrarily.

** Applications of truth trees

The algorithm can be used to:

- Determine whether a wff \(A\) is *satisfiable* and, if so, find truth assignments that satisfy \(A\).
- Determine whether a wff \(A\) is a *contradiction* or a *tautology*.
  - *Contradiction*: tree for \(A\) is finished and closed.
  - *Tautology*: tree for \(\neg A\) is finished and closed.

** Example

Is \(A \equiv \neg((p \vee q) \to (p \wedge q))\) satisfiable? If so, find the satisfying assignments.

#+begin_example
         ¬((p ∨ q) → (p ∧ q)) ✓
                   |
               p ∨ q ✓
                   |
              ¬(p ∧ q) ✓
              /         \
             p           q
           /   \       /   \
         ¬p    ¬q    ¬p    ¬q
          ✗    open  open   ✗
#+end_example

1. Root: \(\neg((p \vee q) \to (p \wedge q))\) is of the form \(\neg(X \to Y)\), an \(\alpha\)-rule giving \(p \vee q\) and \(\neg(p \wedge q)\) on the *trunk*. Tick the root.
2. Apply the \(\beta\)-rule to \(p \vee q\): *branches* \(p\) | \(q\). Tick it.
3. Apply the \(\beta\)-rule to \(\neg(p \wedge q)\) on each *branch*: \(\neg p\) | \(\neg q\). Tick it.
4. Close *branches* with a clash:
   - \(p, \neg p\): closed ✗
   - \(q, \neg q\): closed ✗
5. Two *branches* stay *open* and every wff is used or a *literal*, so *stop*:
   - the tree is *finished and open*.

*Output*: \(A\) is *satisfiable*.

Assign \(T\) to the *literals* on each *open branch*:

| open branch | \(p\) | \(q\) |
|-------------+-------+-------|
| \(p, \neg q\)  | T     | F     |
| \(\neg p, q\)  | F     | T     |
