Parse trees in FOL

Overview

Parse trees for FOL formulae use the same rules for parsing connectives as for wff in PL, plus new rules for:

  • Parsing Atomic Formulae
  • Parsing \((\forall x)X\) and \((\exists x)X\)

Parsing Atomic Formulae

  • Draw a circle containing the predicate letter.
  • Attach a leaf to that circle for every term in the atomic formula.

Example: \(P(x_1, x_2, a)\)

     (P)
    / | \
   /  |  \
(x1) (x2) (a)

Parsing quantified formulae

Parsed the same way as \(\neg X\):

  • Put the quantifier in a circle and attach \(X\) below it with a vertical line.

Universal: \((\forall x)X\)

(∀x)
  |
 (X)

Existential: \((\exists x)X\)

(∃x)
  |
 (X)

Example

Formula: \((\forall x)[(P(x) \rightarrow Q(x)) \wedge S(x, y)]\) 

    (∀x)
      |
     (∧)
    /   \
  (→)   (S)
  / \   / \
(P) (Q)(x) (y)
 |   |
(x) (x)

Reading the tree

  • Root is \(\forall x\), with a single child: the whole bracketed formula.
  • \(\wedge\) is the main connective inside the quantifier, splitting into \(P(x) \rightarrow Q(x)\) and \(S(x, y)\).
  • \(\rightarrow\) splits into the Atomic Formulae \(P(x)\) and \(Q(x)\).
  • Atomic Formulae are circles with the predicate letter, each term hanging below as a leaf.

Summary

Formula Node Children
Atomic predicate letter one leaf per term
\((\forall x)X\) \(\forall x\) one child: \(X\)
\((\exists x)X\) \(\exists x\) one child: \(X\)
\(\neg X\) \(\neg\) one child: \(X\)
\(X \wedge Y\) etc. connective two children: \(X\), \(Y\)
