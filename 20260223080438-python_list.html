Python List

Python List

  • Mutable

Basic Example

lst = [1, 69, 420, 100, 99]

print(*lst)  # 1 69 420 100 99

Insertion

insert()

Insert element at a specific index. 

lst.insert(len(lst), 15)

print(*lst)  # 1 69 420 100 99 15

append()

Add a single element to the end. 

lst.append(6)

print(*lst)  # 1 69 420 100 99 15 6

extend()

Add multiple elements to the end. 

lst.extend([7, 8, 9])

print(*lst)  # 1 69 420 100 99 15 6 7 8 9

Removal

pop()

Remove element at a given index. 

lst.pop(3)

print(*lst)

del

Delete element by index. 

del lst[0]

print(*lst)

Iteration

for x in lst:
    print("Value", x)

Notes

  • Lists in Python are ordered and mutable.
  • insert() is O(n)
  • append() is amortized O(1)
  • extend() is O(k), where k is the number of added elements
  • pop() from end is O(1), otherwise O(n)
  • del depends on position (usually O(n))
