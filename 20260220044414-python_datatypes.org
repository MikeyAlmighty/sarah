#+title: Python DataTypes

* Python Built-in Data Types

| Category       | Data Type  | Example           | Mutable | Description                      |
|----------------+------------+-------------------+---------+----------------------------------|
| Text Type      | str        | "Hello World"     | No      | Sequence of Unicode characters   |
| Numeric Types  | int        | 42                | No      | Integer numbers                  |
| Numeric Types  | float      | 3.14              | No      | Floating-point numbers           |
| Numeric Types  | complex    | 2 + 3j            | No      | Complex numbers                  |
| Sequence Types | list       | [1, 2, 3]         | Yes     | Ordered, changeable collection   |
| Sequence Types | tuple      | (1, 2, 3)         | No      | Ordered, unchangeable collection |
| Sequence Types | range      | range(5)          | No      | Sequence of numbers              |
| Mapping Type   | dict       | {"a": 1, "b": 2}  | Yes     | Key-value pairs                  |
| Set Types      | set        | {1, 2, 3}         | Yes     | Unordered, unique elements       |
| Set Types      | frozenset  | frozenset({1, 2}) | No      | Immutable version of set         |
| Boolean Type   | bool       | True / False      | No      | Logical truth values             |
| Binary Types   | bytes      | b"hello"          | No      | Immutable sequence of bytes      |
| Binary Types   | bytearray  | bytearray(5)      | Yes     | Mutable sequence of bytes        |
| Binary Types   | memoryview | memoryview(bytes) | Depends | Memory view object               |
| None Type      | NoneType   | None              | No      | Represents absence of value      |
