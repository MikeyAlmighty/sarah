* Implementing Interfaces

An *interface* in Java is a [[id:ef3f4798-9f1d-462f-8eea-df2b75e512f6][reference type]], similar to a =class=, that can contain only ~constants~, ~method signatures~, ~default methods~, ~static methods~, and ~nested types~.

It *cannot* contain ~instance fields~ or ~constructors~.

*Interfaces* are used to represent a /contract/ or a set of methods that a =class= *must implement*.

An *interface* is a /class-like/ construct for defining *common* *operations* for =objects=.

An *interface* is an ~abstract data~ type that declares a list of [[id:3e6ed9f7-a719-4f68-94f0-29cb4914ebf2][abstract methods]] that any =class= implementing the interface *must* provide.

In many ways an *interface* is similar to an [[id:3893ce2e-cd85-4914-ba26-d7c7c732eb02][abstract Class]], but its intent is to specify *common* *behavior* for =objects= of related =classes= or unrelated =classes=.

Over time, the precise definition of an ~interface~ has changed, as new method types are now supported.

*Interfaces* enable *multiple inheritance* (a class can ~implement~ *multiple interfaces*) and provide a way to achieve /abstraction/.
