#+title: Conversion Between Strings and Numbers

* Conversion Between Strings and Numbers

** String To Integer

You can convert a =numeric= =string= into a =number=.

To convert a =string= into an =int= value, use the ~Integer.parseInt~.

*** Example

#+BEGIN_SRC java
int intValue = Integer.parseInt(intString);
#+END_SRC

Where =intString= is a *numeric* *string* such as ~"123"~.

** String To Double

To convert a =string= into a =double= value, use the ~Double.parseDouble~.

*** Example

#+BEGIN_SRC java
double doubleValue = Double.parseDouble(doubleString);
#+END_SRC

Where =doubleString= is a *numeric* *string* such as ~"123.45"~.

** Integer To String

You can convert a =number= into a =string=; simply use the string *concatenating* operator as follows:

#+BEGIN_SRC java
String s = number + "";
#+END_SRC

** Error

If the =string= is *not* a =numeric= string, the conversion would cause a *runtime* *error*.

** Note

=Integer= and =Double= classes are both included in the ~java.lang~ package (automatically imported).
