#+title: Conjunctive Clause

* Conjunctive Clause

** Definition

Is a *conjunction* (\(\land\)) of *literals*, where a literal is an atom (\(p\)) or a negated atom (\(\lnot p\)).

- Examples: \(p \land \lnot q \land r\), \(\lnot p \land q\)

** Use in [[id:8efaf8b6-432c-40a2-b1e8-0ebe4db069ae][Functional Completeness]]

For a row of a truth table with value \(T\), the *conjunctive clause* corresponding to that row contains *every atom exactly once*:
- Atom is \(T\) in the row:
  - Write it plain (\(p\))
- Atom is \(F\) in the row:
  - Write it negated (\(\lnot p\))

e.g. Row \((T,F,F)\) = \(p \land \lnot q \land \lnot r\)

- Such a clause is true in *exactly one row* (the row it was built from).
- The *disjunction* of the clauses for all the \(T\) rows gives a *wff* that is ~true~ in exactly those rows: the *Disjunctive Normal Form (DNF)* of \(f\).
