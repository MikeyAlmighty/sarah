Python Dictionary

Python Dictionaries

Basic Example

sample_dict = {1: 'Coffee', 2: 'Tea', 3: 'Juice'}

print(sample_dict[1])  # Coffee

Updating Values

sample_dict[2] = 'Mint Tea'

print(sample_dict[2])  # Mint Tea

Deletion

del sample_dict[3]

print(sample_dict)  # {1: 'Coffee', 2: 'Mint Tea'}

Dictionary Operation Functions

print(type(sample_dict))  # <class 'dict'>

Key Behavior & Overriding

my_d = {'2': True, '1': False, 3: 'dead', 3: 'Pool'}
  • Keys must be unique.
  • Duplicate keys → last value overrides previous.
print(my_d['1'])  # False

print(my_d['3'])
# KeyError: '3'  (string key does not exist)

print(my_d[3])    # Pool (last value overrides)

del my_d[3]

Iteration

Iterate Keys

for key in my_d:
    print(key)

Iterate Key-Value Pairs

for key, val in my_d.items():
    print(str(key) + ":" + str(val))

Notes

  • Dictionaries are unordered (insertion-ordere as of Python 3.7+).
  • Mutable and dynamic.
  • Keys must be immutable types (int, string, tuple, etc.).
  • Fast lookup time: O(1) average case.
  • Internally implemented using hash tables.
