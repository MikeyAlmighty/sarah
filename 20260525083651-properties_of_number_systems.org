#+title: Properties of Number Systems

* Properties of Number Systems

** Summary Table

| Property               | ℕ | ℤ | ℚ | ℝ | ℂ |
|------------------------+---+---+---+---+---|
| Can add and multiply   | ✓ | ✓ | ✓ | ✓ | ✓ |
| Can subtract (ring)    | ✗ | ✓ | ✓ | ✓ | ✓ |
| Can divide (field)     | ✗ | ✗ | ✓ | ✓ | ✓ |
| Ordered                | ✓ | ✓ | ✓ | ✓ | ✗ |
| Induction holds        | ✓ | ✗ | ✗ | ✗ | ✗ |
| Algebraically closed   | ✗ | ✗ | ✗ | ✗ | ✓ |

** Subset Hierarchy

Each system is a subset of the next:

#+begin_example
ℕ ⊂ ℤ ⊂ ℚ ⊂ ℝ ⊂ ℂ
#+end_example

So every *natural number* is an *integer*, every *integer* is *rational*, and so on up to ℂ.

- The /extensions/ are motivated by filling in what each system lacks.

** Reading the Table

- *Ring*: a system where subtraction is always defined. ℕ fails because
  e.g. 3 - 5 ∉ ℕ.
  
- *Field*: a ring where division is always defined (except by zero). ℤ fails
  because e.g. 1/3 ∉ ℤ.
  
- *Ordered*: there is a consistent notion of < between elements. ℂ fails
  because complex numbers cannot be placed on a number line.
  
- *Induction*: the principle of mathematical induction only holds over ℕ, since it relies on a well-defined "next" element with no infinite descent.
  
- *Algebraically closed*: every polynomial has a solution within the system. Only ℂ achieves this — the content of the [[id:71fda1c4-4ba5-48ed-80be-38e869549d15][Fundamental Theorem of Algebra]].
