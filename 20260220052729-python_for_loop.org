#+title: Python For Loop

* For Loop in Python

A ~`for`~ loop is used to iterate over a *sequence* (=list=, =tuple=, =string=, =dictionary=, =set=, =range=, etc.).

Python’s ~`for`~ loop iterates directly over items of a *collection*.

** Basic Syntax

#+begin_src python
for item in iterable:
    # code block
#+end_src


** Example with List

#+begin_src python
numbers = [1, 2, 3, 4]

for num in numbers:
    print(num)
#+end_src


** Using range()

#+begin_src python
for i in range(5):
    print(i)      # 0 to 4
#+end_src

#+begin_src python
for i in range(1, 6):
    print(i)      # 1 to 5
#+end_src

#+begin_src python
for i in range(0, 10, 2):
    print(i)      # 0, 2, 4, 6, 8
#+end_src


** Looping Through a String

#+begin_src python
for char in "Python":
    print(char)
#+end_src


** Looping Through a Dictionary

#+begin_src python
person = {"name": "Alice", "age": 30}

for key in person:
    print(key)

for key, value in person.items():
    print(key, value)
#+end_src


** Using break and continue

#+begin_src python
for i in range(5):
    if i == 3:
        break      # Stops loop
    print(i)
#+end_src

#+begin_src python
for i in range(5):
    if i == 3:
        continue   # Skips iteration
    print(i)
#+end_src


** For-Else Statement

The `else` block runs if the loop completes normally
(no `break`).

#+begin_src python
for i in range(3):
    print(i)
else:
    print("Loop finished")
#+end_src


** Nested Loops

#+begin_src python
for i in range(3):
    for j in range(2):
        print(i, j)
#+end_src


** Key Notes

- Works with any *iterable*.
- Indentation defines the *loop* *body*.
- ~`break`~ exits the loop.
- ~`continue`~ skips to next iteration.
- ~`else`~ runs only if no `break` occurs.
