ArrayList

The ArrayList class in Java is a resizable array implementation of the List.

Unlike traditional arrays, which have a fixed size, an ArrayList can dynamically grow and shrink, making it a flexible data structure for storing elements.

The ArrayList class has the following useful attributes:

  • Allows duplicate elements
  • Maintains insertion order
  • provides index-based access (accessed in constant time using their index).

Example

import java.util.ArrayList;

public class Main {
    public static void main(String[] args) {
        ArrayList<String> names = new ArrayList<>();
        System.out.println("ArrayList Created!");
    }
}

Adding Elements

ArrayList<String> names = new ArrayList<>();
names.add("Alice");
names.add("Bob");
names.add("Charlie");
System.out.println(names); // Output: [Alice, Bob, Charlie]

Accessing Elements

System.out.println(names.get(1)); // Output: Bob

Updating an Element

names.set(1, "David");
System.out.println(names); // Output: [Alice, David, Charlie]

Removing Elements

names.remove(1); // Removes "David"
System.out.println(names); // Output: [Alice, Charlie]
names.remove("Alice"); // Removes "Alice"
System.out.println(names); // Output: [Charlie]

Checking Size

System.out.println("Size: " + names.size()); // Output: Size: 2

Iteration

for (int i = 0; i < names.size(); i++) {
    System.out.println(names.get(i));
}

// Enhanced For
for (String name : names) {
    System.out.println(name);
}

Checking if Element exists

System.out.println(names.contains("Alice")); // Output: true

Clearing the ArrayList

names.clear();
System.out.println(names); // Output: []

Full Code

import java.util.ArrayList;

public class ArrayListExample {

    public static void main(String[] args) {
        ArrayList<String> names = new ArrayList<>();
        System.out.println("ArrayList Created!"); // ArrayList Created!

        // Adding
        names.add("Mikey");
        names.add("Bob");
        names.add("Steve");
        System.out.println(names);// [Mikey, Bob, Steve]

        // Accessing
        System.out.println(names.get(0)); // Mikey
        System.out.println(names.get(2)); // Steve

        // Updating
        names.set(0, "Michael");
        System.out.println(names.get(0)); // Michael

        // Removing
        names.remove(1);
        names.remove("Steve");
        System.out.println(names);// [Michael]

        // Exists?
        System.out.println(names.contains("Alice")); // false
        System.out.println(names.contains("Michael")); // true

        // Length
        System.out.println(names.size()); // 1

        // Clearing
        names.clear();
        System.out.println(names); // []
    }
}

The ArrayList class is a powerful and flexible data structure that provides dynamic resizing and efficient element management.

It is ideal for scenarios where frequent data retrieval is needed with minimal modifications.

It is considered important in polymorphism since it:

  • Enables storing heterogeneous objects= (instances of subclasses).
  • Allows method overriding so that objects exhibit behaviour dynamically.
  • Helps in loose coupling, where code works with a parent class/interface reference rather than concrete implementations.
