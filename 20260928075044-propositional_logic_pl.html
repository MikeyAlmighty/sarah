Propositional Logic (PL)

Propositional Logic (PL): building blocks and syntax

Overview

Syntax means the grammatical rules of a language.

To specify the syntax of propositional logic (PL) we define:

  • the building blocks of the language, and
  • the rules for constructing statements from them.

This note covers the building blocks.

The construction rules (what counts as a well-formed statement) are not covered in this part of the source.

Building blocks

PL statements are built from three kinds of symbol:

  • Atomic Statements
  • Connectives
  • brackets

Atomic statements

  • Atomic statements (or atoms) are a set of symbols, listed as \(p_1, p_2, p_3, \dots\)
  • To avoid subscripts, lowercase letters \(p, q, r, \dots\) are often used instead.

Connectives

The six connectives, in order: \(\lnot\), \(\land\), \(\lor\), \(\oplus\), \(\leftrightarrow\), \(\to\).

  • Unary: \(\lnot\)
  • Binary: \(\land, \lor, \oplus, \leftrightarrow, \to\)

Brackets

Round brackets \((\) \()\) act as the "punctuation marks" of PL.

They make a statement built from atoms and connectives unambiguous.

English analogy: the same words, punctuated differently, mean different things:

  • "The convict said the judge is mad."
  • "The convict, said the judge, is mad."

PL example: \(\lnot(p \leftrightarrow q)\) vs \(\lnot p \leftrightarrow q\)).

Terminology

  • Syntax: the grammatical rules of a language.
  • Atom / atomic statement: a basic symbol (\(p\), \(q\), …) that is not built from other statements.
  • Compound statement: a statement built from atoms using connectives (and brackets).
