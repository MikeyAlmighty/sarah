Using Scanner to Read Data from File

Example

import java.util.Scanner;

public class ReadData {
    public static void main(String[] args) throws Exception {
        // Create a File instance
        java.io.File file = new java.io.File("scores.txt");

        // Create a Scanner for the file
        Scanner input = new Scanner(file);

        // Read data from a file
        while (input.hasNext()) {
            String firstName = input.next();
            String mi = input.next();
            String lastName = input.next();
            int score = input.nextInt();

            System.out.println(firstName + " " + mi + " " + lastName + " " + score);
        }

        // Close the file
        input.close();
    }
}

Notes

  • Invoking the constructor new Scanner(File) may throw an I/O exception, so the main method declares throws Exception.
  • Not necessary to close the input file, but it is a good practice to do so to release the resources occupied by the file. (You can rewrite this program using the try-with-resources syntax)
