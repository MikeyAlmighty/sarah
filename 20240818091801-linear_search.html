1. Linear Search

1.1. Time Complexity:

O(n)

1.2. Description

Linear search (aka sequential search) is a straightforward Algorithm used to find a specific value within a list or Array. (Can be in any order).

1.2.1. overview of how it works:

  1. Start at the Beginning:

    Begin at the first element of the list or array.

  2. Compare Elements:

    Compare the target value (the value you're searching for) with the current element.

  3. Check for Match:

    If the current element matches the target value, the search is successful, and you can return the index of the element. If the current element does not match the target value, move to the next element.

  4. Continue Until Found or End:

    Repeat until: The target value is found, or You reach the end of the list or array.

  5. Handle Absence:

    If you reach the end of the array without finding the target value, the search concludes that the value is not present.

1.3. Example

public class LinearSearch {

    public static int linearSearch(int[] list, int key) {
        for (int i = 0; i < list.length; i++) {

            // return index if found
            if (key == list[i]) {
                return i;
            }

        }
        // return -1 if not found
        return -1;
    }

    public static void main(String[] args) {
        int[] numbers = {4, 2, 7, 1, 9, 3};

        int key1 = 7;
        int key2 = 5;

        int result1 = linearSearch(numbers, key1);
        int result2 = linearSearch(numbers, key2);

        if (result1 != -1) {
            System.out.println("Element " + key1 + " found at index: " + result1);
        } else {
            System.out.println("Element " + key1 + " not found");
        }

        if (result2 != -1) {
            System.out.println("Element " + key2 + " found at index: " + result2);
        } else {
            System.out.println("Element " + key2 + " not found");
        }

    }
}

1.4. Output

Element 7 found at index: 2
Element 5 not found
