#+title: FileWriter vs BufferedWriter

* FileWriter vs BufferedWriter

Several ways to *write* text files.

~FileWriter~ and ~BufferedWriter~ being two of the most commonly used =classes=.

- [[id:6f26410b-0b10-4f78-ad2c-256c817af23a][FileWriter]]
- [[id:f035bb96-4594-4586-a61c-d6086df90e57][BufferedWriter]]
  
| Feature           | FileWriter               | BufferedWriter                 |
|-------------------+--------------------------+--------------------------------|
| Performance       | Slower (writes directly) | Faster (uses buffering)        |
| Memory Usage      | Low                      | Higher (due to buffering)      |
| Best for          | Small files              | Large files or frequent writes |
| New Line Handling | Manually using \n        | newLine() method               |

** Note

- Use ~FileWriter~ for *simple* *file* writing tasks.
- Use ~BufferedWriter~ for *efficient* writing of *large* *files*.
- Always *close* the *writer* to ensure data is properly saved.
