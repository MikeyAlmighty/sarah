#+title: Throw vs Throws

* Throw vs Throws

| throw                                                 | throws                                              |
|-------------------------------------------------------+-----------------------------------------------------|
| Used inside a method to explicitly throw an exception | Used in the method signature to declare exceptions  |
| Followed by an instance of an exception               | Followed by exception class names                   |
| Can only throw a single exception at a time           | Can declare multiple exceptions separated by commas |
