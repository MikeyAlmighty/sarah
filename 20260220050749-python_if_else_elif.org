#+title: Python if/else/elif

* Conditional Statements in Python

** Syntax

#+begin_src python
if condition:
    # code block

elif another_condition:
    # code block

else:
    # code block
#+end_src


** Basic Example

#+begin_src python
x = 10

if x > 0:
    print("Positive")
elif x == 0:
    print("Zero")
else:
    print("Negative")
#+end_src


** Multiple Conditions

#+begin_src python
age = 20

if age < 13:
    print("Child")
elif age < 18:
    print("Teenager")
elif age < 65:
    print("Adult")
else:
    print("Senior")
#+end_src


** Using Logical Operators

#+begin_src python
temperature = 25
is_sunny = True

if temperature > 20 and is_sunny:
    print("Good day for a walk!")
#+end_src


** Nested Conditionals

#+begin_src python
x = 15

if x > 0:
    if x % 2 == 0:
        print("Positive Even")
    else:
        print("Positive Odd")
#+end_src


** Key Notes

- Indentation defines blocks.
- `elif` means "else if".
- Only the first true condition runs.
- `else` is optional.
- Conditions must evaluate to `True` or `False`.
