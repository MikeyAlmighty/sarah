#+title: Properties of Inequalities

* Properties of Inequalities
** Overview

These are the rules for manipulating an inequality (e.g. $a < b$)
without breaking it. They're the tools behind almost every
induction step: take a hypothesis (an inequality) and apply one of
these to nudge it toward the target's shape.

** Rules

*** Add or subtract anything

$$a < b \implies a + c < b + c \quad \text{and} \quad a - c < b - c$$

Always safe, for *any* $c$ — positive, negative, or zero.

*** Multiply or divide by a positive number

$$a < b, \ c > 0 \implies ac < bc \quad \text{and} \quad \frac{a}{c} < \frac{b}{c}$$

Direction stays the same.

*** Multiply or divide by a negative number

$$a < b, \ c < 0 \implies ac > bc$$

*Direction flips.* E.g. $2 < 5$, but multiplying by $-1$ gives
$-2 > -5$.

*** Square (only if both sides are non-negative)

$$0 \leq a < b \implies a^2 < b^2$$

If either side could be negative, squaring can break the
inequality — e.g. $-3 < 2$ but $(-3)^2 = 9 > 4 = 2^2$.

*** Square root (only if both sides are non-negative)

$$0 \leq a < b \implies \sqrt{a} < \sqrt{b}$$

*** Transitivity (chaining)

$$a < b \text{ and } b < c \implies a < c$$

This is how multiple inequality steps get linked into one proof —
e.g. $2^{k+1} < 2(k!) < (k+1)!$ chains to $2^{k+1} < (k+1)!$.

*** Adding two inequalities together

$$a < b \text{ and } c < d \implies a + c < b + d$$

** Common mistakes

- Flipping (or forgetting to flip) direction when multiplying or
  dividing by a negative number.
- Squaring or square-rooting when a side could be negative —
  only valid when both sides are non-negative.
