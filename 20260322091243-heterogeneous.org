#+title: Heterogeneous

* Heterogeneous

** Definition

*Heterogeneous* means consisting of different types.
In Java a *heterogeneous* collection stores objects of different =classes= (=types=), usually related through a *common* =superclass= or =interface=.

*** Example

#+begin_src java
ArrayList animals = new ArrayList<>();

animals.add(new Dog());
animals.add(new Cat());
#+end_src

Here, the ArrayList is *heterogeneous* because it contains *different* *object* types (~Dog~ and ~Cat~).

*** Why it works
- Java uses  [[id:ecaa3f5f-3cd3-4ad3-93dc-1da93d3cf395][polymorphism]] All objects share a common type (e.g., Animal)
- Method calls are resolved at runtime ([[id:a036361c-34a9-4d80-9748-2128f0b99af8][Dynamic Binding]])

*** Contrast

- *[[id:cce1b149-cb9e-428c-9fae-3b10a99eadeb][Homogeneous]]*: *same* *type* only
- *Heterogeneous*: *multiple* *types*

*** Key Insight
Heterogeneous collections rely on:
- *Inheritance*
- *Upcasting* (~subclass~ → ~superclass~)
- [[id:a036361c-34a9-4d80-9748-2128f0b99af8][Dynamic method dispatch]]

*** Summary

*Heterogeneous* = *different* object *types* stored together via a *shared* *parent* *type*.
