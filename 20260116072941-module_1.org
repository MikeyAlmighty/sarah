* Module 1

** Learning Objectives

- *Software Development* process and *job* *roles*:
  - Describe stages of the ~SDLC~.

- Identify *core* components of a =Java= program:
  - Break down the *structure* and *syntax* of a basic =Java= program.
  - Describe the fundamental *building blocks* of =Java= code.

- *Compile* and *run* a =Java= program:
  - Demonstrate the steps to compile and execute a Java program.
  - Apply best practices for successful Java program execution.
    
- Recognise and resolve common *programming* *errors*:
  - Identify common *errors* encountered in Java programming.
  - Implement strategies to troubleshoot and fix these errors.
    
- Utilise software tools for Java development:
  - Introduce and use popular software tools for *writing*, *compiling*, and *running* =Java= programs.
  - Explain the importance of these tools in a developer’s workflow.
