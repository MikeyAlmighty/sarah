#+title: Integer Numbers ($\mathbb{Z}$)

* Integer Numbers ($\mathbb{Z}$)

Denoted by:

\[
\mathbb{Z} = \{\dots, -3, -2, -1, 0, 1, 2, 3, \dots\}
\]

The integers include:
- *Positive* numbers
- *Negative* numbers
- *Zero*

They extend the  [[id:1001ff7b-e2dd-454f-b458-424d8d587d95][Natural Numbers ($\mathbb{N}$)]] by introducing [[id:482d2124-b10f-42e3-a71b-26ee4f369fb0][Additive Inverses]].

* Why We Introduce Integers

We extend \( \mathbb{N} \) to \( \mathbb{Z} \) because subtraction is not always possible in \( \mathbb{N} \).

For example:
- \(2 - 5\) is *not* a natural number.

By introducing *negative numbers*, we ensure that subtraction is always possible.

Thus, in \( \mathbb{Z} \):
- \(2 - 5 = -3\)
- Every number has a corresponding negative counterpart

This extension allows us to perform subtraction without leaving the system.

* Algebraic Structure

The integers form a *ring*.

This means:
- Addition is closed in \( \mathbb{Z} \)
- Subtraction is closed in \( \mathbb{Z} \)
- Multiplication is closed in \( \mathbb{Z} \)

So for any \(a, b \in \mathbb{Z}\):
- \(a + b \in \mathbb{Z}\)
- \(a - b \in \mathbb{Z}\)
- \(a \times b \in \mathbb{Z}\)

However:
- Division is not always closed in \( \mathbb{Z} \)

For example:

\[
1 \div 2 = \frac{1}{2} \notin \mathbb{Z}
\]

So while \( \mathbb{Z} \) improves arithmetic compared to \( \mathbb{N} \), it is still *incomplete* for /division/.

* What Changes Compared to \( \mathbb{N} \)

Moving from \( \mathbb{N} \) to \( \mathbb{Z} \) improves algebraic structure, but changes ordering behavior.

In \( \mathbb{N} \):
- *Every* number can be reached from \(0\) by repeatedly applying the [[id:435da084-f189-49f3-846b-7401dd76cc5e][Successor Function]].

In \( \mathbb{Z} \):
- This is *no* longer true.

Because *integers* extend in both directions:
- *Positive* direction (successors)
- *Negative* direction (predecessors)

So to generate /all integers/ from \(0\), we need:
- *Successor* steps: \(n \mapsto n + 1\)
- *Predecessor* steps: \(n \mapsto n - 1\)

This means:
- There is no single “starting point” that generates all of \( \mathbb{Z} \) using only successors.

* Ordering in \( \mathbb{Z} \)

The integers are still ordered:

\[
\dots < -2 < -1 < 0 < 1 < 2 < 3 < \dots
\]

However, unlike \( \mathbb{N} \), the ordering extends infinitely in both directions.

So:
- There is *no first integer*
- There is *no last integer*

This breaks the simple ~“counting forward”~ structure that underlies *natural numbers*.

* Connection to Structure Loss

Extending number systems often improves algebraic power but may lose structural properties.

From \( \mathbb{N} \) to \( \mathbb{Z} \):
- We gain: subtraction
- We lose: simple *successor-only generation* (and the *induction-style* structure tied to it)

This trade-off becomes a recurring theme in *abstract algebra* and *number systems*.
