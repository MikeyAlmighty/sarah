#+title: FileReader

* FileReader

(Basic File Reading)

- ~FileReader~ used for *reading character files*.
- Reads one character at a time.
- Does *not* buffer data (less efficient for large files).

** Example

#+BEGIN_SRC java
import java.io.FileReader;
import java.io.IOException;

public class FileReaderExample {
    public static void main(String[] args) {
        // Specify the file name
        String fileName = "example.txt";

        // Try-with-resources to automatically close the FileReader
        try (FileReader reader = new FileReader(fileName)) {
            int character;
            System.out.println("Reading file contents:");

            // Read and print each character until the end of the file (-1)
            while ((character = reader.read()) != -1) {
                System.out.print((char) character);
            }
            System.out.println("\nFile reading completed successfully.");
            
        } catch (IOException e) {
            System.out.println("Error reading file: " + e.getMessage());
        }
    }
}
#+END_SRC

*** Disadvantages

- Reads one character at a time, which is *inefficient* for =large files=.
- Does not support buffering, which means *frequent* disk =I/O operations=.
