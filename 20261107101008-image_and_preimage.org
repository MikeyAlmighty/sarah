#+title: Image and Preimage

* Image and Preimage

** Definition

Let $f : A \to B$ and suppose $f(a) = b$. Then:
- $a$ is a *preimage* of $b$ (an input that is sent to $b$).
- $b$ is the *image* of $a$ (the output for input $a$).

An element of $A$ has *exactly one* image, since $f$ is a function.

An element of $B$ can have *zero, one or many* preimages.

** Example

Using the function from [[id:b14f2f86-0696-45cc-80a0-481aa3e536d9][Surjectivity]]: $f(a) = 2$, $f(b) = 2$, $f(c) = 1$, $f(d) = 3$.
- The image of $a$ is $2$.
- $2$ has two preimages: $a$ and $b$.
- $1$ has one preimage: $c$.

** Images and preimages of sets

- *Image of* $S \subseteq A$:
  \[ f(S) = \{ f(x) \mid x \in S \} \]
  The *range* is the *image* of the /whole/ *domain*: $\operatorname{ran}(f) = f(A)$.
- *Preimage of* $T \subseteq B$:
  \[ f^{-1}(T) = \{ x \in A \mid f(x) \in T \} \]
  For example, $f^{-1}(\{2\}) = \{a, b\}$.

The notation $f^{-1}(T)$ does *not* mean that $f$ has an inverse function.
- It just means "everything that lands in $T$".

** Link to surjectivity

$f$ is [[id:b14f2f86-0696-45cc-80a0-481aa3e536d9][surjective]] iff every $b \in B$ has at least one *preimage*, i.e. $f^{-1}(\{b\}) \neq \emptyset$ for all $b \in B$.

** Synonyms

| Term       | Synonyms                                                                                |
|------------+-----------------------------------------------------------------------------------------|
| Image      | value (of $f$ at $a$), output; "$a$ maps to $b$", "$f$ sends $a$ to $b$", $a \mapsto b$ |
| Range      | image of $f$, $\operatorname{im}(f)$, $f(A)$                                            |
| Preimage   | inverse image (mostly for sets), $f^{-1}(T)$                                            |
|            | fibre / fiber (preimage of a single point, $f^{-1}(\{b\})$)                             |
| Surjective | onto ("$f$ maps $A$ onto $B$"); a surjective function is a *surjection*                 |
