#+title: Binary Search

* Binary Search

=Binary search= common search approach for a list of values.
~elements~ in the array must already be *ordered*.

Assume that the array is in ascending order.

The binary search first compares the *key* with the *element* in the *middle* of the ~array~.

Consider the following three cases:
1. If the key is *less* than the ~middle element~, you need to continue to search for the key only in the *first* *half* of the ~array~.
2. If the key is *equal* to the ~middle element~, the *search* *ends* with a =match=.
3. If the key is *greater* than the ~middle element~, you need to continue to search for the key only in the *second* *half* of the ~array~.

** Time Complexity:
O(log n)

** Description
=Binary search= is an efficient algorithm for finding an ~item~ from a [[id:1a328fa4-9b9f-4856-88f3-fd490bce565b][sorted]] list of items.

It works by repeatedly *dividing* the search interval in *half*.

If the value of the search key is *less* than the ~item~ in the *middle* of the ~interval~, the algorithm narrows the ~interval~ to the *lower half*. (Otherwise, it narrows it to the *upper half*.)

This process continues until the ~value~ is *found* or the ~interval~ is *empty*.

** Example

#+BEGIN_SRC java
public class BinarySearchExample {

    public static int binarySearch(int[] arr, int key) {
        int low = 0;
        int hight = arr.length - 1;

        while (low <= hight) {

            int mid = low + (hight - low) / 2;

            if (arr[mid] == key) {
                return mid; // key found
            }

            if (arr[mid] < key) {
                low = mid + 1; // search upper half
            } else {
                high = mid - 1; // search lower half
            }
        }

        return -1; // key not found
    }

    public static void main(String[] args) {

        int[] numbers = {1, 3, 5, 7, 9, 11, 13};

        int key = 7;

        int result = binarySearch(numbers, key);

        if (result != -1) {
            System.out.println("Element found at index: " + result);
        } else {
            System.out.println("Element not found");
        }
    }
}
#+END_SRC
