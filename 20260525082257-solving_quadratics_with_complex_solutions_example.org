#+title: Solving Quadratics with Complex Solutions (Example)

* Problem

Solve:

#+begin_example
z² + 2z + 2 = 0
#+end_example

* Solution

Apply the ~Quadratic Formula~:

#+begin_example
z₁,₂ = ( -b ± √(b² - 4ac) ) / 2a
#+end_example

With a = 1, b = 2, c = 2:

#+begin_example
z₁,₂ = ( -2 ± √(4 - 8) ) / 2
      = ( -2 ± √(-4) ) / 2
      = ( -2 ± 2i ) / 2
      = -1 ± i
#+end_example

So the two solutions are:

| Root | Value  |
|------+--------|
| z₁   | -1 + i |
| z₂   | -1 - i |

* Key Observation

Neither solution is *real*, nor purely *imaginary* — they are [[id:fe99a514-0c3d-48bf-836b-91622b4c1cae][complex numbers]] of the form a + bi, with a = -1 and b = ±1.

- Note also that z₁ and z₂ are *complex conjugates* of each other — this is not a coincidence.

For any quadratic with *real* /coefficients/, *complex roots* always come in [[id:a72e23a6-06f2-4e4d-b163-6571c9abb09d][conjugate pairs]].

* Takeaway

By extending from real → imaginary → complex numbers, *every* quadratic equation becomes solvable.
