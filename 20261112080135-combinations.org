#+title: Combinations

* Combinations

** Definition (8.7)

A *combination of $n$ objects taken $k$ at a time* is any selection of $k$ *distinct* objects from a set of $n$ objects.

- Order /doesn't/ matter ::

  - $\{B, W, K\}$ and $\{W, B, K\}$ are the /same/ combination.

- No repetitions ::

  - Same as [[id:7f49c34b-ea2d-4cbf-9705-5a2c2fbeeb20][Permutations]].

- Synonym ::
  - "Unordered selection /without/ Repetitions".

** Combination rule (Theorem 8.4)

The number of unordered selections of $k$ objects from $n$ objects, without repetitions, is

\[
\binom{n}{k} = \frac{n(n-1)\cdots(n-k+1)}{k!} = \frac{n!}{(n-k)!\,k!}
\]

- Binomial coefficient ::
  - $\binom{n}{k} := \frac{n!}{(n-k)!\,k!}$, read "$n$ choose $k$".

*** Proof

1. Number of /ordered/ selections ([[id:7f49c34b-ea2d-4cbf-9705-5a2c2fbeeb20][Permutations]]): $\frac{n!}{(n-k)!}$.
2. An ordered selection = an /unordered/ selection, /then/ an order for it.
3. There are $k!$ ways to order $k$ elements.
4. By the product rule:
   \[
   \frac{n!}{(n-k)!} = \binom{n}{k} \times k!
   \]
5. Divide both sides by $k!$:
   \[
   \binom{n}{k} = \frac{n!}{(n-k)!\,k!} \quad \blacksquare
   \]

- Intuition ::
  - Permutations over-count each combination $k!$ times (once per ordering), so divide it out.

** Binomial formula

The binomial coefficients appear in the binomial formula, which gives the coefficients for the expansion of a power:

\[
(x+y)^n = \sum_{k=0}^{n} \binom{n}{k} x^k y^{n-k}
\]

- Example ($n = 5$) ::
  \[
  (x+y)^5 = \binom{5}{0}x^0y^5 + \binom{5}{1}x^1y^4 + \binom{5}{2}x^2y^3 + \binom{5}{3}x^3y^2 + \binom{5}{4}x^4y^1 + \binom{5}{5}x^5y^0
  \]
  \[
  = y^5 + 5xy^4 + 10x^2y^3 + 10x^3y^2 + 5x^4y + x^5
  \]
  - Coefficients: $\binom{5}{0}, \binom{5}{1}, \ldots, \binom{5}{5} = 1, 5, 10, 10, 5, 1$.

** Examples

*** Card hands

- Problem ::
  - 13-card hand from a 52-card deck. How many hands?
- Solution ::
  - Unordered, no repetitions, so use $\binom{n}{k}$ with $n = 52$ and $k = 13$:
    \[
    \binom{52}{13} = \frac{52!}{(52-13)!\,13!} = \frac{52!}{39!\,13!}
    \]
  - The $39!$ cancels with the bottom 39 factors of $52!$, leaving a product of 13 terms over $13!$:
    \[
    \binom{52}{13} = \frac{52 \cdot 51 \cdots 40}{13!} = 635\,013\,559\,600
    \]

*** Full house
- Full house ::
  *Three of a kind* plus a *pair*.

- Problem ::
  - *5-card* hand with *3 cards of* /one rank/ and *2 cards* of /another rank/.
  - In a pack of cards there are *13 denominations (ranks)* (2, 3, ..., queen, king, ace), with *4 cards* of /each/ *denomination* (one per /suit/).

  - Denomination Synonym ::
    - "Rank" (also "face value").

- Solution ::

  - Order *doesn't* matter, so we fix a convenient order: choose the *triple* first, then the *pair*.
    1. *Denomination (Rank)* for the triple: *13* choices.
    2. Choose *3* of the *4* cards in that *denomination (rank)*: $\binom{4}{3} = \frac{4!}{(4-3)!\,3!} = 4$ choices.
    3. *Denomination (Rank)* for the pair: *12* choices, since it must differ from the triple's *denomination (rank)*.
    4. Choose *2* of the *4* cards in that *denomination (rank)*: $\binom{4}{2} = \frac{4!}{(4-2)!\,2!} = 6$ choices.
       1. Product rule (each step's choices are independent of the others' values):
          \[
          13 \times 4 \times 12 \times 6 = 3744
          \]
       2. Each full house is counted exactly once, because its *triple* and *pair denominations (ranks)* are determined by the hand, so no further division is needed.

*** Number of subsets of an $n$ -element set

Two approaches, both giving $2^n$.

1. *Sum over sizes* ::
   - Subsets of size $k$: $\binom{n}{k}$.
   - A subset has size $0$ /or/ $1$ /or/ ... /or/ $n$:
     \[
     \sum_{k=0}^{n} \binom{n}{k} = (1+1)^n = 2^n
     \]
   - Uses the binomial formula with $x = y = 1$.

2. *In or out* ::
   - Each of the $n$ elements is either /in/ the subset or /not/: 2 choices.
   - Every distinct set of $n$ choices gives a different subset:
     \[
     \underbrace{2 \times 2 \times \cdots \times 2}_{n} = 2^n
     \]
