Learning Objectives

  • Understand exceptions and exception handling and the basic exception handling syntax.
  • Understand the difference between throw and throws.
  • Understand why and how to create custom exception classes.
  • Apply the best practices for exception handling and properly use logging and debugging strategies.
  • Properly read text files using FileReader and BufferedReader.
  • Properly write text files using FileWriter and BufferedWriter.
  • Apply advanced Text I/O with the use of java.io.file package.
  • Understand how to read data from the Web.
  • Properly use exception handling in file operations.
