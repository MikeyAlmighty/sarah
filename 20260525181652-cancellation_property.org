#+title: Cancellation Property

* Cancellation Property

The set of [[id:0284d4d3-5609-484d-a5a3-f79c1d062af2][Integer Numbers ($\mathbb{Z}$)]] enjoys the *cancellation* property:

#+begin_example
if  a ≠ 0  and  ab = ac  then  b = c
#+end_example

You can cancel a common non-zero factor from both sides without dividing
- important in ℤ where *division* is not always defined.

This property provides a natural setting for the study of *divisibility*.

Note: if a = 0, then ab = ac collapses to 0 = 0 for any b and c, so the condition a ≠ 0 is essential.

* Divisibility

** Definition

For *integers* a, b with a ≠ 0, we say *a /divides/ b* if there exists an integer *q* such that:

#+begin_example
b = qa
#+end_example

Notation:
- a ∣ b  — a divides b
- a ∤ b  — a does not divide b

** Terminology

When b = qa:

| Name                  | Role |
|-----------------------+------|
| Divisor / factor      | a    |
| Dividend / multiple   | b    |
| Quotient              | q    |

** Examples

#+begin_example
3 ∣ 9     since  9  = 3 × 3
3 ∤ 17    since  17 = 3 × 5 + 2  (remainder, no integer quotient)
3 ∣ 315   since  315 = 3 × 105
#+end_example
