#+title: Sum Rule

* Sum Rule

** Statement

If there are \(n(A)\) ways to do \(A\) and, *distinct from them*, \(n(B)\) ways to do \(B\), then the number of ways to do \(A\) *or* \(B\) is

\[ n(A) + n(B) \]

Extends to any number of disjoint options: \(n(A) + n(B) + n(C) + \dots\)

** Key Idea

- Keyword: *OR*:
  - You pick exactly /one/ option from one of several groups.
- Condition: the groups must be *disjoint* (no outcome counted in two groups).
- Set form: if \(A \cap B = \emptyset\) then \(|A \cup B| = |A| + |B|\).
- If the groups overlap, use *inclusion–exclusion* instead: \(|A \cup B| = |A| + |B| - |A \cap B|\).

** Example:  Committee Representative

One representative from 1st year (500), 2nd year (300) or 3rd year (100).

Students are all different, pick one from any year:

\[ 500 + 300 + 100 = 900 \]

** Example: File Names (with [[id:f90c0002-ff3d-4bda-8cc9-f00e49f9a3f8][Product Rule]])

Names of length 1, 2 or 3; first symbol a letter (26), others letter or digit (36).
- Length 1: \(26\)
- Length 2: \(26 \times 36 = 936\)
- Length 3: \(26 \times 36^2 = 33\,696\)
Cases are disjoint (by length), so sum: \(26 + 936 + 33\,696 = 34\,658\).
