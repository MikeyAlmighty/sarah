1. Interface Inheritance

In Java, an interface can inherit from one or more interfaces using the extends Keyword.

Unlike classes, interfaces support multiple inheritance.

2. Syntax

interface A {
    void methodA();
}

interface B {
    void methodB();
}

interface C extends A, B {
    void methodC();
}
  • C inherits all methods from A and B
  • Any class implementing C must implement all inherited methods.

3. Example

interface Animal {
    void makeSound();
}

interface Pet {
    void play();
}

interface Dog extends Animal, Pet {
    void guard();
}

class MyDog implements Dog {

    public void makeSound() {
        System.out.println("Bark");
    }

    public void play() {
        System.out.println("Playing");
    }

    public void guard() {
        System.out.println("Guarding");
    }
}

4. Key Rules

  • Interfaces use extends to inherit from other interfaces
  • A class uses implements to implement interfaces
  • Interfaces can extend multiple interfaces
  • Classes can implement multiple interfaces
  • Methods are implicitly public abstract (unless default or static)
  • Fields are implicitly public static final

5. Default Method Conflict

If two interfaces provide the same default method, the implementing class must resolve it: 

interface A {
    default void hello() {
        System.out.println("Hello from A");
    }
}

interface B {
    default void hello() {
        System.out.println("Hello from B");
    }
}

class Test implements A, B {
    @Override
    public void hello() {
        A.super.hello(); // resolve conflict
    }
}

6. Key Idea

An interface can combine multiple behaviors, forming a flexible inheritance hierarchy without the limitations of class inheritance.
