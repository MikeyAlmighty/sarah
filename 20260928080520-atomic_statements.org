#+title: Atomic Statements

* Atomic Statements

- Also called *atoms*.
- Can be true (\(T\)) or false (\(F\)).
- Denoted by symbols \(p, q, r, \ldots\)

*** Goal
In ~PL~ we would like to form new, and possibly more complicated, statements using the atoms
=p,q,r …=.

We would like to do this in such a way that, if we know whether the atomic statements
=p,q,r,…= are *true* or *false*, then we can decide whether our new "complicated" statement is *true* or *false*.
