#+title: FileReader vs BufferedReader

* FileReader vs BufferedReader

- [[id:28556018-cd47-434c-b6fd-3ec7222583f8][FileReader]]
- [[id:9a299a9d-8c57-489e-95c5-483007f2b4a8][BufferedReader]] 
  
| Feature           | FileReader                    | BufferedReader                  |
|-------------------+-------------------------------+---------------------------------|
| Reads per Call    | 1 character                   | 1 line (or multiple characters) |
| Efficiency        | Less efficient                | More efficient (buffers data)   |
| read() Method     | Reads one character at a time | Reads characters into a buffer  |
| readLine() Method | Not available                 | Available                       |
| Use Case          | Small files                   | Large files                     |
