1. Python Set

1.1. Basic Example

set_a = {1, 2, 3, 4, 5, 5}

print(set_a)  # duplicates automatically removed
  • Sets are unordered.
  • Duplicate values are automatically removed.

1.2. Insertion

1.2.1. add()

Add a single element. 

set_a.add(6)
print(set_a)

1.3. Removal

1.3.1. remove()

Removes an element. Raises KeyError if element is not found. 

set_a.remove(2)
print(set_a)

1.3.2. discard()

Removes an element. Does NOT raise error if element is missing. 

set_a.discard(4)
print(set_a)

1.4. Set Operations

set_b = {5, 6, 7, 8, 9}

1.4.1. Union

Combine elements from both sets. 

print(set_a.union(set_b))  # {1, 3, 5, 6, 7, 8, 9}
print(set_a | set_b)       # same result

1.4.2. Intersection

Common elements. 

print(set_a.intersection(set_b))  # {5, 6}
print(set_a & set_b)              # same result

1.4.3. Difference

Elements in set_a but not in set_b. 

print(set_a.difference(set_b))  # {1, 3}
print(set_a - set_b)            # same result

1.4.4. Symmetric Difference

Elements in either set but not both. 

print(set_a.symmetric_difference(set_b))  # {1, 3, 7, 8, 9}
print(set_a ^ set_b)                      # same result

1.5. Indexing (Not Allowed)

Sets are unordered and not subscriptable. 

print(set_a[0])
# TypeError: 'set' object is not subscriptable

1.6. Notes

  • Sets are unordered and mutable.
  • Cannot contain mutable types (like lists or other sets).
  • Fast membership testing: O(1) average case.
  • Backed by hash tables internally.
