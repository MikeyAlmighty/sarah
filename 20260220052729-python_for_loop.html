1. For Loop in Python

A `for` loop is used to iterate over a sequence (list, tuple, string, dictionary, set, range, etc.).

Python’s `for` loop iterates directly over items of a collection.

1.1. Basic Syntax

for item in iterable:
    # code block

1.2. Example with List

numbers = [1, 2, 3, 4]

for num in numbers:
    print(num)

1.3. Using range()

for i in range(5):
    print(i)      # 0 to 4

for i in range(1, 6):
    print(i)      # 1 to 5

for i in range(0, 10, 2):
    print(i)      # 0, 2, 4, 6, 8

1.4. Looping Through a String

for char in "Python":
    print(char)

1.5. Looping Through a Dictionary

person = {"name": "Alice", "age": 30}

for key in person:
    print(key)

for key, value in person.items():
    print(key, value)

1.6. Using break and continue

for i in range(5):
    if i == 3:
        break      # Stops loop
    print(i)

for i in range(5):
    if i == 3:
        continue   # Skips iteration
    print(i)

1.7. For-Else Statement

The `else` block runs if the loop completes normally (no `break`). 

for i in range(3):
    print(i)
else:
    print("Loop finished")

1.8. Nested Loops

for i in range(3):
    for j in range(2):
        print(i, j)

1.9. Key Notes

  • Works with any iterable.
  • Indentation defines the loop body.
  • `break` exits the loop.
  • `continue` skips to next iteration.
  • `else` runs only if no `break` occurs.
