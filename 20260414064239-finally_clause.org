#+title: Finally clause

* Finally Clause

The ~finally clause~ is *always executed*.

** Syntax

#+BEGIN_SRC java
try {
    // Statements
} catch (TheException ex) {
    // handling Exception
} finally {
    // finalStatements
}
#+END_SRC

*** Usage

- Often for *closing files* and for *cleaning up resources*.
- The ~finally~ block executes even if there is a =return statement= prior to reaching the ~finally block~.

*** Note

The ~catch block~ may be *omitted* when the ~finally clause~ is used:

**** Example

#+BEGIN_SRC java
try {
    // ...    
} finally {
    // ....  
}
#+END_SRC
