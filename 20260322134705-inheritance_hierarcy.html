Inheritance Hierarcy

An inheritance hierarchy is the structure formed when multiple classes are related through Inheritance, creating a chain or tree-like relationship.

  • At the top of every hierarchy in Java is the Object class.

Structure

Example hierarchy: 

Object
  ↑
Person
  ↑
Employee
  ↑
Faculty
  • Person inherits from Object
    • Employee inherits from Person
      • Faculty inherits from Employee

Key Idea

An object of a subclass contains:

  • Its own fields and methods
  • All inherited fields and methods from its ancestors.

Constructor Execution

  • When creating an object, constructors are invoked from the top of the hierarchy down:
Object → Person → Employee → Faculty
  • This process is called constructor chaining

Method Resolution

When a method is invoked on an object:

  • The JVM starts searching from the actual type (most specific class).
  • Then moves up the hierarchy until the method is found.

This is known as dynamic binding.

Example

class Person {
    public String toString() {
        return "Person";
    }
}

class Employee extends Person {
    @Override
    public String toString() {
        return "Employee";
    }
}

class Faculty extends Employee {
}

public class Test {
    public static void main(String[] args) {
        Person p = new Faculty();
        System.out.println(p.toString());
    }
}

Output

Employee

Explanation

  • Declared type: Person
  • Actual type: Faculty
  • Faculty does not override toString()
  • JVM searches: Faculty → Employee → Person
  • Finds method in Employee

Important Rules

  • Java supports single inheritance for classes.
  • Every class implicitly extends Object.
  • Subclasses inherit accessible members from superclasses.
  • Private members are not inherited.
  • Constructors are not inherited, but are invoked.
